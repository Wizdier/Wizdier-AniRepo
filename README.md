# Wizdier-AniRepo

Aniyomi anime extension repository.

## Extensions

| Extension | Lang | Version | 
|-----------|------|---------|
| Miruro.tv | en   | 3       |

## Building

```bash
./gradlew :src:en:miruro:assembleRelease
```

The APK will be at: `src/en/miruro/build/outputs/apk/release/`

## Requirements

- JDK 11+
- Android SDK (compileSdk 34)
